# Spec Delta

## Purpose

明确首个完整版本之后可选择的格式和阅读增强，保证技术评估不会偷偷改变上传文件或把整体下载描述成分块读取；后续 Agent 可以据此提出有证据的接入方案，而不会将增强项混入本轮主体或降低四种首发格式要求。

## ADDED Requirements

### Requirement: 其他格式直接解析
系统 MUST 在选择实施 MOBI、AZW3/KF8、FB2 时优先直接解析并保留原件，明确 DRM 与整体下载限制；若候选统一库无法按需读取，不得损坏 EPUB/PDF/漫画既有资源边界。可选阶段 7；来源 33、61、230–234、333、474–476 行。

#### Scenario: 候选适配器需整本下载
- **WHEN** 评估发现某格式必须完整获取才能解析
- **THEN** 标注真实限制并做大文件测试，不能宣称已实现分块按需或后台强制转成EPUB。

### Requirement: 可选增强独立验收
系统 SHALL 将自定义本地/服务器字体、PDF双页、Webtoon/自动裁边、复杂书签管理/文字高亮、服务器目录增量扫描和长期离线包作为独立验收的可选任务；基础定位书签属于既有阅读能力，不与高级高亮混为一谈。阶段7/P1；来源146、157、164、342、348、436、476行。

#### Scenario: 未实施增强
- **WHEN** 交付阶段1–6但尚未实施可选增强
- **THEN** 清单准确保持未完成状态，界面不提供虚假入口，原件下载/删除/元数据编辑/断点续传仍须另外确认。
