# Spec Delta

## Purpose

为部署在个人域名上的 iRead 提供适合单用户的安全边界，避免为了简单而泄露原件、阅读内容或管理员凭据；身份会话、不可信上传及内容隔离必须在相应资源功能接入前通过验证，开发骨架不能冒充可公网使用的产品。

## ADDED Requirements

### Requirement: 单管理员与安全退出
系统 MUST 在真实资源接入前提供首次部署设置管理员密码、可靠密码散列、HttpOnly/SameSite Cookie 会话与安全退出，不增加注册、角色或多用户体系。阶段 2 硬前置；来源 31、89、439 行。

#### Scenario: 退出后访问
- **WHEN** 管理员退出后再次请求原件、页面、设置或进度 API
- **THEN** 会话失效且受保护资源不可访问；密码/Token 不出现在前端源码或 URL 中。

### Requirement: 未鉴权主体限本机开发
系统 MUST 明确标识阶段 1 尚未具备接入保护，只绑定本机开发入口，不将骨架部署到公网；健康检查不泄露本机路径或敏感配置。阶段 1；本轮已确认范围。

#### Scenario: 启动未鉴权主体
- **WHEN** 开发者按默认说明或 compose 启动本轮主体
- **THEN** 端口仅发布到回环地址，文档和界面准确说明资源能力尚未接入，未宣称认证已完成。

### Requirement: 上传与归档安全边界
系统 MUST 验证真实 MIME、扩展名、大小及归档内容，限制解压量/压缩比/图片像素/时间/内存，拒绝路径穿越与危险链接；所有资源访问使用经过验证的书籍标识与路径。阶段 2、6 硬前置；来源 236、297、339、405 行。

#### Scenario: 恶意文件与路径
- **WHEN** 上传 ZIP bomb、穿越路径、恶意符号链接或超大图片，或请求另一条任意磁盘路径
- **THEN** 操作被拒绝并返回统一可理解错误，宿主文件和其他书籍不受影响。

### Requirement: 阅读内容隔离
系统 MUST 隔离 EPUB 等不可信内容中的活动脚本、网络与顶层导航能力，防止内容访问应用会话和 DOM，同时保持图片、字体、CSS 和内部链接可读。阶段 3 硬前置；来源 334、405 行。

#### Scenario: EPUB 内嵌脚本
- **WHEN** 打开包含脚本、外链和导航攻击的 EPUB 章节
- **THEN** 攻击不能访问管理员凭据、主应用或任意原件路径，可读正文与必要相对资源仍能正确展示。
