# Spec Delta

## Purpose

使 EPUB 文字书在桌面和手机上按实际阅读位置获取章节与附件，并在字体、宽度和阅读模式变化后保留稳定的原文位置；正确处理出版物结构和样式，禁止以整本下载冒充按需阅读或为统一适配器牺牲资源边界。

## ADDED Requirements

### Requirement: EPUB 章节资源化
系统 MUST 直接解析 EPUB 2/3 并按章节及独立 CSS/图片/字体提供资源，只请求当前与附近区域，不先下载整本 Blob/ArrayBuffer。阶段 3；来源 225、326–334 行。

#### Scenario: 打开大型 EPUB
- **WHEN** 用户打开并跳到一个章节
- **THEN** 网络证据仅包含必要索引、当前章节及有限相邻附件，不出现无条件全书传输；相对 URL、目录和内部链接正确。

### Requirement: 重排保持原文位置
系统 SHALL 以稳定定位符及必要文本锚点恢复章节内位置，支持滚动/分页与适用的宽屏双栏；修改样式只失效受影响排版缓存。阶段 3；来源 144–153、331–333 行。

#### Scenario: 修改字号与切换布局
- **WHEN** 用户在章节中部修改字体/行高/宽度或切换分页滚动
- **THEN** 恢复到同一段落附近，不回到章节开头，已获取章节网络资源不重复下载。

### Requirement: 出版方样式与阅读工具
系统 SHALL 保留出版物可读结构，提供跟随出版方/优先用户样式、目录、内部跳转与适用的书签基础，并与单书覆盖和统一调度联动。阶段 3；来源 146–153、200、348 行。

#### Scenario: 切换出版方样式
- **WHEN** 用户改变 CSS 优先级或从目录跳转章节
- **THEN** 正文结构、图片、字体及链接可用，跳转目标成为新的可见位置并触发有限双向窗口。

### Requirement: EPUB视口与真实正文事件
系统 SHALL 将实际可用视口与带单位边距传递到分页器，保留合理用户宽度；真实正文document内的键盘/轻触须触发正确导航且不抢链接、选区或滚动，章节与会话卸载清理监听。

#### Scenario: 阅读器修订闭环
- **WHEN** 用户执行本轮已确认的阅读器操作
- **THEN** 改变边距/窗口或在正文内操作后，页区占用与用户设置一致，locator稳定，工具栏/翻页真实生效且不重复触发。
