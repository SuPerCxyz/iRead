# Spec Delta

## Purpose

在 EPUB、PDF 与漫画之间共享资源调度原则和可靠的续读状态，而保留各自正确的资源粒度；通过有界双向缓存、过时任务取消及修订冲突处理，保证前进后退复用、快速跳转响应和跨端恢复都有可观察证据。

## ADDED Requirements

### Requirement: 三层缓存及稳定身份
系统 MUST 区分网络资源、短期渲染和受限持久缓存；缓存身份包含书籍、原件版本、资源位置，渲染缓存额外包含样式/缩放版本；清理派生缓存不删原件/进度。阶段 3–6；来源 238–261、377 行。

#### Scenario: 样式失效与前后复用
- **WHEN** 用户前进→后退→前进或修改 EPUB 字号
- **THEN** 已有网络资源不重复下载，只重建必要排版；PDF 第100→101→100→99→101页的命中/重建符合有限预算。

### Requirement: 有界双向预加载
系统 MUST 优先可见区域，提供节省前1/后1、均衡前2/后4、极速前3/后6的候选窗口并按设备保存，按阅读方向和速度动态调整；刚离开的页保留保护期。资源量、时间、内存、并发受限，停止阅读不逐步下载全书。阶段 3–6；来源 263–284 行。

#### Scenario: 移动设备停在一页
- **WHEN** 用户停留或切换预加载档位
- **THEN** 仅维护受限候选窗口，移动起始并发2、桌面3–4作为待实测起点，高分辨率 Canvas 单独预算，不等同于窗口页数。

#### Scenario: 快速反向
- **WHEN** 用户快速前进后立即反向阅读
- **THEN** 方向/速度改变候选优先级，刚离开的页仍能命中，旧远端任务取消或降级，不能因窗口抖动重复下载邻页。

### Requirement: 取消去重与生命周期
系统 SHALL 合并同一在途资源请求、局部重试失败，快速跳转优先新目标并取消/降级旧任务；路由切换、切书和卸载清理订阅、计时器、Worker及大对象。阶段 3–6；来源 267–274、390–395 行。

#### Scenario: 快速跳转和旧响应
- **WHEN** 用户从第10→500→20页且旧请求迟到
- **THEN** 第20页优先，进度保留最终落点，旧响应不能占用新会话；离开后渲染对象与监听器可释放。

### Requirement: 精准定位与修订同步
系统 MUST 使用格式定位符、模型版本、更新时间和 revision 记录续读；节流本地写入并同步服务端，章节切换/退出/隐藏尽可能立即保存；网络失败落本地后恢复对账。阶段 3–6；来源 344–366 行。

#### Scenario: 断网与跨端向后阅读
- **WHEN** 手机断网向后读、切后台，再恢复网络并在电脑打开
- **THEN** 不仅以较大百分比判新旧，不让旧 revision 静默覆盖较新位置；先恢复缓存位置再对账，不闪回第1页。

### Requirement: 可观察性能和真实验收
系统 SHALL 在开发模式按需展示命中率、队列、在途/取消请求、字节/Canvas/窗口/跳页耗时，生产默认隐藏；长读与大书性能报告必须注明环境、样本、实测和未验证项。阶段 5–6；来源 286–288、379–430 行。

#### Scenario: 完整版本性能验收
- **WHEN** 验收1000–3000本书库、300MB PDF和30–60分钟阅读
- **THEN** 提供网络列表/下载量、命中取消数、响应时间和内存/对象释放证据，不能用配置、模拟器或单测代替实测。

### Requirement: 基础定位书签闭环
系统 SHALL 提供当前稳定位置的书签创建、持久列表、定位跳转和移除，保留格式/fileVersion身份及失败恢复；只移除书签记录，不删除原件/进度/偏好。阶段3基础接口与EPUB、阶段4 PDF、阶段6漫画；来源348行及既有基础书签要求，复杂管理/高亮为P1。

#### Scenario: 创建跳转与移除
- **WHEN** 用户创建当前位置书签、重开列表、跳转该位置并移除书签
- **THEN** 返回同一原件的稳定locator，重复提交不重复建记录，移除后列表更新且图书仍在；失联/条件冲突显示失败并保留可恢复状态，过期原件版本不跳回第1页。
