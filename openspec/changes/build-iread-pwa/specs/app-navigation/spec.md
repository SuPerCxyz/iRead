# Spec Delta

## Purpose

为 iRead 的首页、书库、详情、阅读和设置提供连贯的桌面与移动使用路径；保证导航、反馈、键盘焦点和返回状态一致，并明确区分已经接入的功能和后续阅读能力，避免静态样例冒充实际结果。

## ADDED Requirements

### Requirement: 五条可直接访问的路由
系统 SHALL 提供 `/`、`/library`、`/books/:id`、`/read/:id`、`/settings`，支持浏览器历史与深链接；未知路径有可恢复的 404。阶段 1；来源 79–95、444–448 行。

#### Scenario: 深链接与未知页面
- **WHEN** 用户直接访问设置、详情或不存在的路径
- **THEN** 分别呈现对应页面或 404，并能返回首页/书库；不得落入服务器文件目录或空白页。

### Requirement: 真实状态与可恢复反馈
系统 SHALL 明确区分空书库、未接入图书能力、网络错误和不存在的资源，错误提供有效恢复入口；不得伪造书籍、进度、统计或不可执行的操作。阶段 1–2；来源 25、184–195、440、478 行。

#### Scenario: 初始主体与断网
- **WHEN** 用户在尚未接入图书服务的阶段打开首页、书库或详情
- **THEN** 页面准确说明当前能力并允许真实导航；上传、搜索等未实现操作不伪装为可用按钮。
- **AND** 设置保存失败时保留当前外观并显示原因及重试，而非仅输出控制台异常。

### Requirement: 阅读器隔离外壳与返回状态
系统 SHALL 在阅读路由隐藏外层侧栏、顶栏和移动底栏；退出可回到进入前的书库地址与滚动位置。阶段 1 框架、阶段 3–6 真实内容；来源 56、110–114、197–202 行。

#### Scenario: 从书库返回
- **WHEN** 用户从已滚动的书库进入详情/阅读页并后退
- **THEN** 恢复此前的列表状态与滚动位置，已缓存的内容不被全屏 Loading 替换。

### Requirement: 移动导航与可访问交互
系统 SHALL 提供手机主页/书库/设置底部导航、适合单手使用的 Sheet，以及安全区、动态视口和横竖屏适配；所有入口支持键盘、可见焦点和可读标签。阶段 1 框架、阶段 3–6 阅读手势；来源 126、204–217 行。

#### Scenario: 打开与关闭移动导航
- **WHEN** 用户以触控或键盘打开 Sheet、按 Esc 或关闭按钮
- **THEN** 焦点进入面板、关闭后回到触发入口，背景不可误操作且手机页面没有横向溢出。

### Requirement: 阅读控制不抢输入与手势
系统 SHALL 在真实阅读接入后按格式提供中间轻触工具栏、目录/设置 Sheet、左右键翻页、Esc退出、F全屏、S目录、`/`搜索；支持配置且避免抢占输入、文字选择、纵向滚动和PDF缩放。阶段 3–6；来源 201、212–215 行。

#### Scenario: 选择文字与缩放
- **WHEN** 用户在正文长按选择、编辑输入框或双指缩放 PDF
- **THEN** 不触发误翻页或全局快捷键；工具栏变化不重建整本书或丢失位置。
