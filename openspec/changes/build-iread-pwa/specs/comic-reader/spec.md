# Spec Delta

## Purpose

提供适合 CBZ 和 CBR 的漫画阅读路径，在服务器安全索引归档后按独立页面读取，保留原始压缩包不变；自然排序、阅读方向、展示模式与移动交互保持一致，不能把 CBR 依赖或整包下载问题隐藏为已完成支持。

## ADDED Requirements

### Requirement: 两类归档按页读取
系统 MUST 在首个完整版本同时支持 CBZ 和 CBR 的服务器按页资源，不要求客户端下载整包，不转换/改写原件；CBR 解析依赖须隔离、限时并报告错误。阶段 6，非可选；来源 227–228、336–342、470–472 行。

#### Scenario: 打开 CBZ 与 CBR
- **WHEN** 打开文件名为 page1、page2、page10 的漫画并翻页
- **THEN** 图片自然排序，网络仅获取索引和当前/有限邻页，RAR 依赖缺失或损坏归档有明确失败提示而非假成功。

### Requirement: 漫画阅读模式和准确续读
系统 SHALL 提供左到右/右到左、单页/双页/纵向连续、适应屏幕/宽度/原始尺寸、页距与背景，按书保存方向、模式与准确页码。阶段 6；来源 162–166、340、357 行。

#### Scenario: 横竖屏与返回阅读
- **WHEN** 用户改变方向/展示模式或旋转手机后退出重开
- **THEN** 恢复准确页及书籍偏好，单手导航不与滚动、缩放和工具栏手势冲突。

### Requirement: 图片内存与派生清理
系统 SHALL 按显示需要使用受限尺寸的派生图片，预取可取消，释放远处解码对象；清缓存不影响原件、定位和偏好。阶段 6；来源 234、341、387 行。

#### Scenario: 大图与快速跳页
- **WHEN** 连续阅读超大图片或快速跳到远处
- **THEN** 内存不随已读页数无限增加，旧解码/预取取消或降级，可见页面优先；清缓存后能从原件重建。
