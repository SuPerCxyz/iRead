# Spec Delta

## Purpose

让 iRead 的页面、书架和阅读正文始终遵守同一套视觉规则，并允许用户即时改变适合自己的外观；设置在重新打开和设备间恢复时保持清晰的版本、继承和单书覆盖关系，失败时不丢失当前体验。

有效优先记录：用户最新硬约束为“页面内容严格使用模板内容，不要自定义样式”，并已确认方案1：sidebar-07+shadcn官方默认组件组合iRead业务内容，保留动态阅读设置。旧自主视觉方案失效；唯一样式文件等价集中模板样式，不改默认皮肤。用户主动调整是受控业务覆盖，与开发者私自换皮不同；来源/映射/字段范围与恢复行为见[ui-design](../../ui-design.md)，下列动态设置P0全部保留。

## ADDED Requirements

### Requirement: 统一视觉与样式来源
系统 MUST 严格使用用户确认模板的页面内容与样式，唯一样式文件只等价集中模板样式；不得自主设计皮肤或分散硬编码颜色、间距、字号、圆角、阴影、断点或动画。阶段1起持续生效；本轮最新要求优先于源文116–126行的冲突视觉参数。

#### Scenario: 增加组件
- **WHEN** 后续 Agent 增加页面、组件或 shadcn 变体
- **THEN** 保留已确认模板内容/样式，在唯一来源等价汇集；门禁拒绝额外样式、自创设计值或借变量分散硬编码，不能把模板原有class简单判成必须重写。

### Requirement: 外观调整即时生效并保存
系统 SHALL 提供系统/浅色/深色主题、强调色与密度的即时切换，保留当前路由和滚动；本地与服务器持久化且有保存/失败/恢复反馈。阶段 1 基础外观；来源 121–138 行。

#### Scenario: 保存与重新打开
- **WHEN** 用户修改主题、强调色、密度并重新打开应用
- **THEN** 不需手动刷新即可看到新外观，重开后恢复最近成功保存值；请求延迟不能覆盖用户刚做的新选择。

#### Scenario: 保存失败与冲突
- **WHEN** 本地存储不可用、服务器离线或设置修订发生冲突
- **THEN** 当前预览仍生效，界面明确说明未保存的范围，提供重试或载入服务器值；旧请求不得静默覆盖新设置。

### Requirement: 完整书架外观控制
系统 SHALL 在真实书库接入后提供暖纸/纯白/深灰/深蓝黑预设、可读的自定义强调色、网格/列表、封面密度、作者/百分比/格式/副标题显隐、封面比例圆角、卡距、内容宽度和导航紧凑度。阶段 2–3；来源 130–138 行。

#### Scenario: 修改书架显示
- **WHEN** 用户调整卡片显示、密度或内容宽度
- **THEN** 当前书架即时重排、保持滚动上下文，重开后恢复；自定义颜色不能让文本和操作失去对比度。

### Requirement: 按格式呈现阅读设置
系统 SHALL 仅展示当前格式实际支持的设置：文字书字体/字重/字号/行高/段距/缩进/对齐/边距/宽度/分页滚动/双栏/动画/颜色/出版方 CSS；PDF 单页/连续纵向/适应宽度/适应整页/横向、缩放/页距/背景/工具栏（双页P1）；漫画方向/单双页/连续/适应模式。阶段 3–6；来源 140–166 行。

#### Scenario: 固定版式与即时重排
- **WHEN** 用户阅读 PDF 或修改 EPUB 字体、宽度、分页模式
- **THEN** PDF 不提供虚假的内嵌字体/行距控制；EPUB 即时重排并尽量保持原文段落；可选 PDF 反色默认关闭且说明颜色失真。

### Requirement: 三级继承和版本化持久化
系统 SHALL 区分应用外观、书库显示、全局阅读偏好和单书覆盖，按照内置默认→用户全局→单书覆盖解析；显示继承来源并提供仅本书、设为全局、恢复本书默认操作。阶段 3；来源 168–178 行。

#### Scenario: 单书恢复继承
- **WHEN** 用户只改一本书的字号后恢复此书默认，再从其他浏览器或 PWA 打开
- **THEN** 单书覆盖被移除并恢复全局继承，全局值未被意外修改；带模型版本的值在本地和服务器恢复一致。

### Requirement: 本书安全自动保存与完整正文偏好
系统 SHALL 对本书编辑即时预览并先持久本机草稿，再防抖串行按revision保存；全局默认仅显式修改。既有字重/主题/正文颜色字段须完整作用阅读内容，错误/断网/重开/冲突保留用户意图。

#### Scenario: 阅读器修订闭环
- **WHEN** 用户执行本轮已确认的阅读器操作
- **THEN** 本书自动保存成功后仍可显式将本次字段设全局；恢复默认废弃旧草稿，迟到请求不回写，其他书覆盖不受影响。
